# Cookies Manager Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the app use a browser's cookies (one global choice) so login/age/bot failures go away, with the per-platform cookie file still overriding.

**Architecture:** Pass yt-dlp a `cookiesfrombrowser` tuple when no cookie file is present. A Cookies dialog (File -> Cookies) sets the global browser choice in QSettings; the choice is baked into job options like `cookies_file`. No cookie is ever read, written, or committed by the app.

**Tech Stack:** Python 3.8+, PyQt5 (GUI), yt-dlp (existing).

**Spec:** `docs/specs/2026-10-16-cookies-design.md`

## Global Constraints

- Python 3.8+; **no new dependencies**.
- `core/` stays **Qt-free and thread-free** (enforced by `tests/test_core_isolation.py`). `sites/cookies.py` stays Qt-free.
- **Security (binding):** the app never reads a browser profile and never writes a cookie file; it only passes a browser name to yt-dlp. **Tests must never touch a real browser profile** - they fake yt-dlp and assert the options dict only. Never commit a cookie file.
- The suite must stay green: `python -m pytest -q` (baseline 415 passing).
- Lint prints 0: `python -m flake8 . --count --select=E9,F63,F7,F82 --show-source --statistics`
- Conventional Commits. **Never commit a real social-media URL** (use `https://a.com/1`, `https://youtu.be/x`). **Never push** without approval.
- Precedence: a cookie file wins; the browser is the fallback.

```python
class CookiesDialog(QtWidgets.QDialog):
    """Choose a browser to source cookies from. Never reads a browser."""

    def __init__(self, parent=None):
        super().__init__(parent)
        from sites.cookies import BROWSERS, app_dir, cookie_status
        from utils.ui_helpers import reveal_in_folder

        self.setWindowTitle("Cookies")
        self.resize(520, 360)
        layout = QtWidgets.QVBoxLayout(self)

        row = QtWidgets.QHBoxLayout()
        row.addWidget(QtWidgets.QLabel("Use cookies from:"))
        self.browser_combo = QtWidgets.QComboBox()
        self.browser_combo.setAccessibleName("Cookies browser")
        self.browser_combo.addItem("No cookies", "")
        for browser in BROWSERS:
            self.browser_combo.addItem(browser.capitalize(), browser)
        saved = QtCore.QSettings().value("cookies/browser", "") or ""
        index = self.browser_combo.findData(saved)
        self.browser_combo.setCurrentIndex(index if index >= 0 else 0)
        row.addWidget(self.browser_combo)
        row.addStretch(1)
        layout.addLayout(row)

        layout.addWidget(QtWidgets.QLabel("Cookie files found:"))
        self.status_list = QtWidgets.QListWidget()
        self.status_list.setAccessibleName("Cookie file status")
        for _platform, name, path in cookie_status():
            self.status_list.addItem("%s: %s" % (name, path or "none"))
        layout.addWidget(self.status_list)

        buttons = QtWidgets.QDialogButtonBox(
            QtWidgets.QDialogButtonBox.Ok | QtWidgets.QDialogButtonBox.Cancel
        )
        buttons.accepted.connect(self.accept)
        buttons.rejected.connect(self.reject)
        open_btn = buttons.addButton(
            "Open cookie folder", QtWidgets.QDialogButtonBox.ActionRole
        )
        open_btn.clicked.connect(lambda: reveal_in_folder(app_dir()))
        layout.addWidget(buttons)

    def chosen_browser(self) -> str:
        return self.browser_combo.currentData()
```

```python
                      cookies_path: str, subtitles: str = "off",

        "outtmpl": os.path.join(save_dir, "%(title)s.%(ext)s"),
        "output_type": output_type,
        "convert": output_type == "MP4",
        "target_resolution": int(resolution),

        "subtitles": subtitles,
        "cookies_from_browser": cookies_from_browser,
```
