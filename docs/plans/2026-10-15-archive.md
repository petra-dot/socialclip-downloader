# Archive (Skip Already-Downloaded) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the Queue a persistent archive so re-runs skip videos already downloaded (default off, GUI + CLI).

**Architecture:** Reuse yt-dlp's `download_archive` (records `extractor id`, skips internally). `download_one` detects the skip and returns a `skipped` result; `core/queue.py` maps it to a new terminal `skipped` job state. New pure `core/archive.py` owns the file path and clearing.

**Tech Stack:** Python 3.8+, PyQt5 (GUI), yt-dlp (existing).

**Spec:** `docs/specs/2026-10-15-archive-design.md`

## Global Constraints

- Python 3.8+; **no new dependencies**.
- `core/` stays **Qt-free and thread-free** (enforced by `tests/test_core_isolation.py`).
- The suite must stay green: `python -m pytest -q` (baseline 399 passing).
- Lint prints 0: `python -m flake8 . --count --select=E9,F63,F7,F82 --show-source --statistics`
- Conventional Commits. **Never commit a real social-media URL** (use `https://a.com/1`, `https://youtu.be/x`). **Never push** without approval.
- `skipped` mirrors `cancelled`: `status="error"` + `error_category="skipped"`, set explicitly (never from `sites/errors.py`). The archive applies to the Queue only, not the single Download tab or `download`.

import os

from sites.cookies import app_dir


def default_archive_path() -> str:
    """The archive file: archive.txt beside queue.json and presets.json."""
    return os.path.join(app_dir(), "archive.txt")


def clear_archive(path: str) -> bool:
    """Delete the archive file. Returns whether a file was removed.

    Never raises: a missing file, a directory in its place, or a permission
    error all return False so the caller can report "nothing to clear".
    """
    try:
        os.remove(path)
        return True
    except OSError:
        return False

def _queue_executor(job, archive=None):
    from core.download import download_one

    opts = job.options or {}
    outtmpl = resolve_outtmpl(opts)
    return download_one(
        job.url,
        outtmpl=outtmpl,

        target_resolution=opts.get("target_resolution", 1080),

def _run_cli_job(job, archive=None):
    try:
        return job, _queue_executor(job, archive=archive)
    except Exception as exc:  # noqa: BLE001 - one job must not kill the pool
        from core.manifest import error_result
        return job, error_result("other", str(exc), job.url)

        from core.archive import default_archive_path
        archive = default_archive_path() if args.archive else None
        run = done = failed = cancelled = skipped = 0
        with ThreadPoolExecutor(max_workers=args.jobs) as pool:
            pending = set()
            while True:
                while len(pending) < args.jobs:
                    job = queue.claim_next()
                    if job is None:
                        break
                    pending.add(pool.submit(_run_cli_job, job, archive))
                if not pending:
                    break
                finished, pending = wait(pending, return_when=FIRST_COMPLETED)
                for future in finished:
                    job = _apply_cli_result(queue, future)
                    queue.store.save()
                    run += 1
                    if job.state == "done":
                        done += 1
                    elif job.state == "failed":
                        failed += 1
                    elif job.state == "cancelled":
                        cancelled += 1
                    elif job.state == "skipped":
                        skipped += 1
        result = {"schema_version": SCHEMA_VERSION, "run": run, "done": done,
                  "failed": failed, "cancelled": cancelled, "skipped": skipped}
        if args.json:
            print(json.dumps(result))
        else:
            print(f"run {run}: {done} done, {failed} failed, "
                  f"{cancelled} cancelled, {skipped} skipped")
        return EXIT_OK
