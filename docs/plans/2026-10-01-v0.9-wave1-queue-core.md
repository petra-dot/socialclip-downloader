# v0.9 Wave 1 — Queue Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a persistent download queue with pause/resume/cancel (including mid-download abort) behind a Qt-free core, plus a queue worker, CLI commands, and a queue tab that replaces the batch tab.

**Architecture:** A new `core/queue.py` holds jobs, a JSON store, and a pull-based scheduler (`run_once` runs exactly one item) so the GUI thread loop and the CLI loop share it. `core/download.py` gains a `cancel` callable checked in the yt-dlp progress hook; when set it raises `DownloadCancelled`, the partial artifact is cleaned up, and a `"cancelled"` result is returned.

**Tech Stack:** Python 3.8+, yt-dlp, PyQt5 (GUI only), pytest, stdlib `json`/`dataclasses`/`threading`.

**Spec:** `docs/specs/2026-10-01-v0.9-queue-media-design.md`

## Global Constraints

- `core/` must not import PyQt5 (guarded by `tests/test_core_isolation.py`).
- Error categories remain the six existing plus `"cancelled"`; the download result contract `schema_version` stays `"1.0"`.
- `download_one`'s new parameters are keyword-only additions with defaults; existing callers must keep working unchanged.
- Only files this run created are deleted on cancel; pre-existing files are never touched.
- `QueueStore.save()` is explicit; no autosave on mutation.
- `core/queue.py` has no threads; the worker does.
- All existing tests stay green (99 at plan time). Conventional Commits on a branch.

In `core/download.py`:

```python
class DownloadCancelled(Exception):
    """Raised from the progress hook when the caller requests cancellation."""


def _cleanup_partial(path):
    """Remove the artifact and <base>*.part siblings this run created."""
    import glob
    if not path:
        return
    base, _ = os.path.splitext(path)
    for candidate in [path] + glob.glob(base + "*.part"):
        try:
            if os.path.isfile(candidate):
                os.remove(candidate)
        except OSError:
            pass
```

Extend the signature with keyword defaults:

```python
def download_one(url, outtmpl, output_type, convert, target_resolution,
                 cookies_file=None, progress=None, cancel=None,
                 subtitles=False, embed_thumbnail=False, format_id=None):
```

Declare `in_flight = {"path": ""}` before the `with`, and have the hook record the
path yt-dlp is writing (the progress dict carries it) **and** check cancel:

```python
        in_flight = {"path": ""}

        def hook(d):
            # yt-dlp puts the in-progress filename in the progress dict.
            if d.get("filename"):
                in_flight["path"] = d["filename"]
            if cancel and cancel():
                raise DownloadCancelled()
            if d.get("status") == "downloading":
                ...
```

Wrap the `YoutubeDL` usage so `DownloadCancelled` is handled distinctly from
generic errors, above the existing `except Exception`:

```python
        with YoutubeDL(ydl_opts) as ydl:
            info = ydl.extract_info(url, download=True)
            if not info:
                return error_result("not_found", ..., url)
            downloaded_file = ydl.prepare_filename(info)
    except DownloadCancelled:
        _cleanup_partial(in_flight["path"])
        return error_result("cancelled", "Cancelled.", url)
```

Rationale for the hook capture: when cancellation fires, `extract_info` raises, so
`ydl.prepare_filename(info)` is never reached and `info` is unavailable. The
progress dict's `filename` is the only place the in-flight path exists at that
moment — this is why `_cleanup_partial` receives `in_flight["path"]`, not a local
that does not exist yet.

Also update the `test_cancel_removes_partial_files` fake so the hook receives a
`filename`, making the test exercise the real path:

```python

                  "total_bytes": 10, "filename": str(artifact)})
```

and define `artifact` **before** the class so the closure can see it (build the
fake inside the test body with `artifact` in scope, as the test already does).

The unused new params (`subtitles`, `embed_thumbnail`, `format_id`) are reserved
for wave 3; leave them accepted and unused.

```python
import json

from core.manifest import DownloadResult
from core.queue import Queue, QueueStore


def test_add_and_next_pending_is_fifo():
    q = Queue()
    a = q.add("https://a.com/1", {})
    b = q.add("https://b.com/2", {})
    assert a.state == "pending"
    assert q.next_pending().id == a.id
    a.state = "done"
    assert q.next_pending().id == b.id


def test_run_once_records_success():
    q = Queue()
    job = q.add("https://a.com/1", {})

    def executor(j):
        return DownloadResult(status="ok", url=j.url, path="C:/out.mp4", bytes=10)

    done = q.run_once(executor)
    assert done.id == job.id
    assert done.state == "done"
    assert done.path == "C:/out.mp4"
    assert done.attempts == 1


def test_run_once_records_failure_without_raising():
    q = Queue()
    q.add("https://a.com/1", {})

    def executor(j):
        raise RuntimeError("boom")

    done = q.run_once(executor)
    assert done.state == "failed"
    assert "boom" in done.message


def test_run_once_records_cancelled():
    q = Queue()
    q.add("https://a.com/1", {})

    def executor(j):
        return DownloadResult(status="error", url=j.url,
                              error_category="cancelled", message="Cancelled.")

    done = q.run_once(executor)
    assert done.state == "cancelled"


def test_pause_blocks_run_once():
    q = Queue()
    q.add("https://a.com/1", {})
    q.pause()
    assert q.paused is True
    assert q.run_once(lambda j: None) is None
    q.resume()
    assert q.paused is False


def test_cancel_all_marks_pending_cancelled():
    q = Queue()
    a = q.add("https://a.com/1", {})
    b = q.add("https://b.com/2", {})
    q.cancel_all()
    assert a.state == "cancelled"
    assert b.state == "cancelled"


def test_store_round_trip(tmp_path):

    q = Queue(QueueStore(str(path)))
    q.add("https://a.com/1", {"output_type": "MP3"})

    reopened = Queue(QueueStore(str(path)))
    reopened.store.load()

    assert reopened.jobs[0].url == "https://a.com/1"
```

- [ ] **Step 3: Implement `core/queue.py`**

Requirements:
- `QueueJob` is a `@dataclass` with the fields listed above; `id` is `uuid4().hex`; `created_at` is `datetime.now(timezone.utc).isoformat()`; `options` is `field(default_factory=dict)`.
- `QueueStore.__init__(path)` keeps `path`; `load()` reads the file, tolerates missing/corrupt/unknown-version by leaving `self.jobs = []` and `self.paused = False`; `save()` writes atomically-ish (write then replace) as `{"version": 1, "paused": self.paused, "jobs": [asdict(j) for j in self.jobs]}`.
- `Queue` holds `self.store` (a `QueueStore`; if None, use an in-memory store whose path is `""` and whose `save()` is a no-op) and `self.jobs` (list of `QueueJob`).
- `next_pending()` returns the first job with `state == "pending"`, else None.
- `run_once(executor)`: if `paused`, return None. Get next pending; if none, None. Set `state = "running"`, `attempts += 1`. Call `executor(job)` inside try/except. On a `DownloadResult` with `status == "ok"` → `state="done"`, copy `path`/`bytes`/`height`/`message`. With `error_category == "cancelled"` → `state="cancelled"`. Otherwise → `state="failed"`, `message` from the result. On exception → `state="failed"`, `message=str(exc)`. Return the job. Never raise.
- `pause()`/`resume()` set `self.paused`; `cancel_all()` sets every non-terminal job to `"cancelled"`; `cancel_job(id)` does one.
