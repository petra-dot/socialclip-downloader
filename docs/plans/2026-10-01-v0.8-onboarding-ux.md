# v0.8 Onboarding and UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the GUI start working on paste, show per-URL batch state, diagnose problems before a download fails, and link to the finished file.

**Architecture:** A new `core/doctor.py` builds one structured health report consumed by both the CLI and a GUI dialog. The batch worker gains one additive signal carrying per-item state; the batch tab becomes a table driven by it. Pure helpers (`looks_like_url`, `reveal_in_folder` command builder) live in `utils/` and are tested without a GUI.

**Tech Stack:** Python 3.8+, PyQt5, yt-dlp, pytest. No new runtime dependencies.

**Spec:** `docs/specs/2026-10-01-v0.8-onboarding-ux-design.md`

## Global Constraints

- `core/` must not import PyQt5 (guarded by `tests/test_core_isolation.py`).
- The **doctor report** `schema_version` is `"1.1"`. The **download result** contract stays `"1.0"`. They are independent numbers.
- `run_checks()` never raises; each check degrades to `false`/`null` plus a detail string.
- New batch signal is additive: `status_signal(str)` and `finished_signal(str)` keep their exact current behavior.
- `reveal_in_folder(path)` always receives the **final artifact** (the `.mp3`/converted file when post-processing ran).
- GUI is not unit-tested (repo convention). Pure logic must be testable without a display.
- All existing tests stay green. Conventional Commits. Work on a branch, never commit to `main` directly.

```python
def cookie_file_for(platform: str, cookie_dir: str = None) -> str:
    """Path to this platform's cookie file, or "" when absent."""
    if cookie_dir is None:
        cookie_dir = default_cookie_dir()
    candidates = [
        os.path.join(cookie_dir, f"{platform}_cookies.txt"),
        os.path.join(cookie_dir, f"{platform}.txt"),
    ]
    for path in candidates:
        if os.path.isfile(path):
            return path
    return ""
```

```python
import os
import re
import subprocess
import sys

_SCHEME = re.compile(r"^[a-z][a-z0-9+.-]*://", re.IGNORECASE)
_HOSTISH = re.compile(r"^[\w-]+(\.[\w-]+)+(/\S*)?$")


def looks_like_url(text: str) -> bool:
    text = (text or "").strip()
    if not text:
        return False
    if _SCHEME.match(text):
        return True
    return bool(_HOSTISH.match(text))


def reveal_command(path: str, platform: str = None) -> list:
    platform = platform or sys.platform
    if platform.startswith("win"):
        return ["explorer", "/select," + path.replace("/", "\\")]
    if platform == "darwin":
        return ["open", "-R", path]
    return ["xdg-open", os.path.dirname(path)]


def reveal_in_folder(path: str) -> None:
    try:
        subprocess.run(reveal_command(path), check=False)
    except Exception:
        pass
```
